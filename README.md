# thebroadercollective.com

Static site for The Broader Collective, LLC, hosted on GitHub Pages.

- `index.html` is the whole site (HTML and CSS in one file, no build step).
- `fonts/` holds self-hosted Sora and Manrope (SIL Open Font License; licenses included).
- `CNAME` tells GitHub Pages the custom domain. Don't delete it.
- `.nojekyll` tells GitHub Pages to serve files as-is.

To update the site, edit the files and commit to `main`. GitHub Pages republishes within a minute or two.
